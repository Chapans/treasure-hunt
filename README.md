# Treasure Hunt

A simple game concept about exploring an island and finding hidden treasure.

## How to play

- Start at the beach with a map and three energy points.
- Choose a location: the forest, cave, or abandoned dock.
- Spend one energy point to explore and reveal a clue.
- Use the clues to pick a treasure location before energy runs out.

## First version

One small map, three clues, and a randomized treasure spot. A round takes about two minutes.

## Optional Solana idea

A future devnet prototype could record completed treasure hunts. The first version can work entirely offline.
